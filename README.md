# Автопостинг в Telegram-чаты

Бот публикует ваши посты в группы и каналы по расписанию. Управляет ботом только один человек — владелец,
чей Telegram ID указан в настройках.

Как это работает:

1. Добавляете бота администратором в чат — чат появляется кнопкой в боте.
2. Открываете чат и создаёте рассылку: присылаете боту посты (текст, фото, видео, альбомы, премиум-эмодзи,
   кнопки) и задаёте расписание — сколько раз в день, во сколько, по каким дням.
3. Сохраняете рассылку как черновик и в пару нажатий переносите её в другие чаты.

## Возможности

- **Любые посты.** Текст с форматированием, фото, видео, GIF, файлы, аудио, голосовые, кружки, стикеры,
  live-фото и альбомы до 10 файлов. Пост публикуется ровно так, как вы его прислали: спойлеры,
  подпись над медиа, настройки превью ссылок и **премиум-эмодзи** сохраняются.
- **Кнопки под постом:** ссылки, кнопки «скопировать текст», цвет (зелёная, красная, синяя) и иконка
  из премиум-эмодзи.
- **Несколько рассылок в одном чате.** В каждой может быть несколько постов, они выходят по очереди
  или в случайном порядке.
- **Расписание:**
  - точное время (`09:00 13:30 18:00`) или «N раз в день» — бот сам равномерно распределит публикации
    в выбранные часы;
  - дни недели, случайный разброс ±5–30 минут (чтобы посты выглядели живыми);
  - период «с … по …»: одна дата и одно время дают разовый пост.
- **Опции:** публикация без звука, защита от пересылки, закрепление (прошлый пост открепляется),
  удаление прошлого поста рассылки, выбор темы в форумах.
- **Черновики.** Сохраните рассылку, примените её к нескольким чатам сразу (выбор галочками),
  а после правок черновика обновите все эти чаты одной кнопкой.
- **Удобство:**
  - предпросмотр постов, кнопка «🚀 Отправить сейчас»;
  - список ближайших публикаций;
  - общая пауза всех рассылок;
  - резервная копия базы в один клик.
- **Надёжность:**
  - после перезапуска бот не публикует пропущенные посты пачкой;
  - один слот никогда не отправляется дважды — даже если бот упал посреди отправки;
  - ошибки приходят вам уведомлением, после 5 ошибок подряд рассылка встаёт на паузу;
  - если бота удалили из чата, его рассылки ставятся на паузу.
- **Доступ только у владельца.** Сообщения и нажатия от других людей игнорируются. Если бота добавил
  в чат кто-то другой, бот спросит вас, принять этот чат или выйти из него.

## Быстрый старт

### 1. Создайте бота и узнайте свой ID

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте токен
   (вида `123456789:AA...`).
2. Узнайте свой числовой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).

> Для премиум-эмодзи бота лучше создавать с аккаунта, у которого есть Telegram Premium
> (подробности — в разделе «Премиум-эмодзи» ниже).

### 2. Заполните настройки

```bash
cp .env.example .env
```

Откройте `.env` и впишите `BOT_TOKEN` и `ADMIN_ID`. Остальные параметры можно не трогать.

| Параметр    | Что это                                                        | По умолчанию       |
|-------------|----------------------------------------------------------------|--------------------|
| `BOT_TOKEN` | токен от @BotFather                                            | — (обязательно)    |
| `ADMIN_ID`  | ваш Telegram ID — единственный, кто управляет ботом            | — (обязательно)    |
| `TIMEZONE`  | часовой пояс расписаний (потом можно сменить в боте)           | `Europe/Moscow`    |
| `DB_PATH`   | файл базы данных                                               | `data/autopost.db` |
| `LOG_LEVEL` | подробность логов                                              | `INFO`             |

### 3. Запустите

**Через Docker (рекомендуется для сервера):**

```bash
docker compose up -d --build
docker compose logs -f        # логи; выход — Ctrl+C
```

Бот перезапускается сам после сбоев и перезагрузки сервера. База хранится в томе `autopost-data`.

**Без Docker** (нужен Python 3.11 или новее):

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

Откройте бота в Telegram и отправьте `/start`.

## Как добавить чат

Любым из способов:

- **Кнопки «➕ Добавить группу» и «➕ Добавить канал» внизу экрана.** Telegram покажет ваши чаты
  и сам сделает бота администратором с нужными правами.
- **Вручную:** настройки группы или канала → Администраторы → добавить бота.
- Ссылками «➕ Группа» и «➕ Канал» в разделе «💬 Мои чаты».

Чат сразу появится в «💬 Мои чаты», а бот пришлёт уведомление.

Какие права нужны боту:

| Где    | Публикация                          | Закрепление                    | Удаление прошлого поста           |
|--------|-------------------------------------|--------------------------------|-----------------------------------|
| Группа | достаточно быть администратором     | «Закрепление сообщений»        | права не нужны (свои сообщения)   |
| Канал  | «Публикация сообщений»              | «Редактирование сообщений»     | «Публикация сообщений»            |

Кнопка «🔄 Обновить права» на экране чата перечитывает права бота.

## Рассылки

**Мои чаты → чат → «➕ Новая рассылка»**, затем:

1. **📝 Посты → ➕ Добавить посты.** Присылайте сообщения по одному — каждое станет постом.
   Можно переслать пост из своего канала: его кнопки подтянутся автоматически. В конце нажмите «✅ Готово».
2. **⏰ Расписание.** Задайте время или «N раз в день», дни недели, разброс и период.
3. **⚙️ Опции** — по желанию.
4. **👁 Предпросмотр** — бот пришлёт посты вам так, как они выйдут в чате.
5. **▶️ Запустить.**

Если в рассылке несколько постов, за каждый слот расписания выходит один пост — по очереди или случайно.
Если пост в рассылке один, он выходит каждый раз. В карточке поста можно показать его, поменять кнопки,
заменить содержимое, передвинуть или удалить.

### Кнопки под постом

Карточка поста → «🔘 Кнопки». Одна строка — один ряд, `|` разделяет кнопки в ряду:

```
Наш сайт - https://example.com
Канал - t.me/my_channel | Чат - @my_chat
Купить - https://shop.example.com - green
Промокод - copy:SALE2026 - blue
```

- Цвет кнопки: `green`, `red`, `blue` (или «зелёная», «красная», «синяя»).
- `copy:ТЕКСТ` — кнопка, которая копирует текст (например, промокод).
- Премиум-эмодзи в начале текста кнопки становится её иконкой.
- К альбомам Telegram не позволяет прикреплять кнопки.

### Режим пересылки

Если пост переслан (например, из вашего канала), в его карточке можно включить «↪️ Публиковать пересылкой».
Тогда пост уходит с плашкой «Переслано из…» и выглядит точно как оригинал, включая премиум-эмодзи.
Бот пересылает его из вашей переписки с ботом, поэтому не удаляйте исходное сообщение из этого чата.

## Черновики

- **💾 В черновики** на экране рассылки сохраняет её посты, расписание и опции.
- **📤 Применить к чатам** — отметьте чаты галочками и нажмите «🚀 Применить и запустить»
  (или «💾 Применить на паузе»).
- В чате можно выбрать **«📝 Из черновика»**.
- **🔄 Обновить во всех** — после правки черновика изменения переносятся во все чаты, где он применён.
  Повторное применение не создаёт дублей: рассылка в чате обновляется.
- Тема форума, статус и счётчики у каждой рассылки свои и при обновлении не меняются.

## Премиум-эмодзи

Это ограничение Telegram, а не бота:

- **В группах** бот показывает премиум-эмодзи, если у **владельца бота** есть Telegram Premium.
  Владелец бота — аккаунт, который создал его в @BotFather (он может не совпадать с `ADMIN_ID`).
- **В каналах** бот показывает премиум-эмодзи, только если ему куплен дополнительный юзернейм на
  [Fragment](https://fragment.com). Иначе они выглядят как обычные эмодзи. Обход — режим пересылки
  (см. выше).

«👁 Предпросмотр» сам проверяет, отобразились ли премиум-эмодзи, и подсказывает, если нет.

## Ограничения Telegram, о которых полезно знать

- Удалить прошлый пост можно, только пока ему меньше 48 часов. Если публикации реже, бот предупредит.
- Плашку «бот закрепил сообщение» бот удалить не может: Telegram не присылает ботам их собственные
  служебные сообщения.
- Подпись к медиа у ботов — до 1024 символов (у Premium-пользователей бывает длиннее, бот это проверит).
- Список тем форума через Bot API получить нельзя, поэтому тему задают ссылкой: тема → ⋯ → «Копировать ссылку».

## Резервная копия и перенос

- **⚙️ Настройки → 💾 Резервная копия** — бот пришлёт файл базы со всеми чатами, рассылками и черновиками.
- Чтобы восстановить или перенести бота на другой сервер: остановите бота, положите файл на место базы
  (`data/autopost.db` или том Docker) и запустите бота снова.
- В Docker можно скопировать базу в текущую папку:
  `docker compose cp bot:/app/data/autopost.db ./autopost.db`.

Не запускайте два экземпляра бота с одной базой — второй сам откажется стартовать.

## Обновление

```bash
git pull
docker compose up -d --build       # или просто перезапустите python -m bot
```

## Проверка после установки

1. `/start` — открылось меню, внизу кнопки «➕ Добавить группу/канал».
2. Добавьте бота в тестовую группу — пришло уведомление, чат появился в «Мои чаты».
3. Создайте рассылку, добавьте пост с альбомом и пост с премиум-эмодзи и кнопками, нажмите «👁 Предпросмотр».
4. «🚀 Отправить сейчас» — пост появился в группе.
5. Задайте время на ближайшую минуту и нажмите «▶️ Запустить» — пост вышел по расписанию.
6. «💾 В черновики» → «📤 Применить к чатам» → выберите второй чат — рассылка появилась там.
7. Удалите бота из группы — пришло уведомление, рассылки встали на паузу.

## Частые вопросы

**Бот не отвечает на /start.** Проверьте `ADMIN_ID`. В логах бот пишет
`Игнорирую апдейт от постороннего пользователя <id>` — это ваш настоящий ID, если он не совпадает с указанным.

**Чат не появился в списке.** Бот должен быть администратором (в группе можно и участником).
Нажмите «➕ Добавить группу/канал» внизу и выберите этот чат — бот зарегистрирует его.

**Посты не выходят.** Откройте рассылку: там статус, ближайшие запуски и последняя ошибка. Проверьте:

- не стоит ли общая пауза (⚙️ Настройки);
- есть ли у бота права в чате;
- правильный ли часовой пояс.

**Время публикаций смещено.** Смените часовой пояс в «⚙️ Настройки → 🌍 Часовой пояс».
Расписания пересчитаются сразу.

## Для разработчиков

Python 3.11+, [aiogram 3.31](https://docs.aiogram.dev/) (Bot API 10.3), SQLAlchemy 2 + aiosqlite.

```
bot/
  __main__.py      запуск, блокировка второго экземпляра
  config.py        настройки из .env
  app.py           контейнер зависимостей и настройки, меняемые из бота
  setup.py         сборка диспетчера (middleware и порядок роутеров)
  db/              модели, подключение к SQLite и репозиторий
  handlers/        обработчики: команды, чаты, рассылки, посты, расписание, опции, черновики, настройки
  middlewares/     доступ только владельцу, сборка альбомов
  services/        планировщик, отправка постов, приём контента, кнопки, расчёт расписания
  ui/              экраны, клавиатуры, тексты, callback-данные
tests/             юнит- и интеграционные тесты (фейковый Telegram записывает запросы бота)
```

```bash
pip install -r requirements-dev.txt
pytest            # тесты
ruff check .      # линтер
ruff format .     # форматирование
```
