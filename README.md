# Автопостинг в Telegram-чаты

Бот публикует ваши посты в группы и каналы по расписанию. Управляют ботом только админы —
люди, чьи Telegram ID указаны в настройках (одного или нескольких).

Как это работает:

1. Добавляете бота администратором в чаты — каждый чат появляется кнопкой в боте.
2. Создаёте рассылку: галочками отмечаете чаты, присылаете боту посты (текст, фото, видео, альбомы,
   премиум-эмодзи, кнопки) и задаёте расписание — сколько раз в день, во сколько, по каким дням.
3. Рассылка публикует одни и те же посты по одному расписанию во все отмеченные чаты. Все посты собраны
   в разделе «🗂 Мои посты», а черновики — заготовки, из которых рассылки создаются в пару нажатий.

## Возможности

- **Любые посты.** Текст с форматированием, фото, видео, GIF, файлы, аудио, голосовые, кружки, стикеры,
  live-фото и альбомы до 10 файлов. Пост публикуется ровно так, как вы его прислали: спойлеры,
  подпись над медиа, настройки превью ссылок и **премиум-эмодзи** сохраняются.
- **Кнопки под постом:** ссылки, кнопки «скопировать текст», цвет (зелёная, красная, синяя) и иконка
  из премиум-эмодзи.
- **Одна рассылка — много чатов.** Чаты отмечаются галочками прямо в рассылке, посты, расписание
  и опции у них общие. Рассылок может быть сколько угодно, и один чат может быть в нескольких рассылках.
  В рассылке может быть несколько постов, они выходят по очереди или в случайном порядке.
- **Мои посты.** Все посты из всех рассылок и черновиков в одном списке: открыть, изменить, удалить,
  скопировать в другую рассылку или сделать из поста новую рассылку.
- **Расписание:**
  - точное время (`09:00 13:30 18:00`) или «N раз в день» — бот сам равномерно распределит публикации
    в выбранные часы;
  - дни недели, случайный разброс ±5–30 минут (чтобы посты выглядели живыми);
  - период «с … по …»: одна дата и одно время дают разовый пост.
- **Опции:** публикация без звука, защита от пересылки, закрепление (прошлый пост открепляется),
  удаление прошлого поста рассылки, выбор темы в форумах (у каждого чата своя).
- **Черновики.** Сохраните рассылку как заготовку, запустите её в нужных чатах (выбор галочками),
  а после правок черновика обновите созданные из него рассылки одной кнопкой.
- **Защита чатов.**
  - Антиспам молча удаляет спам участников групп: ссылки, пересылки, @ботов и @каналы, рекламу
    от имени каналов, стоп-слова.
  - Обязательная подписка: писать в чате могут только подписчики выбранных каналов. Остальным бот
    показывает личные ссылки-приглашения на каналы (у каждого человека — новые) и кнопку
    «✅ Проверить подписку».
- **Удобство:**
  - предпросмотр постов, кнопка «🚀 Отправить сейчас»;
  - список ближайших публикаций;
  - общая пауза всех рассылок;
  - резервная копия базы в один клик.
- **Надёжность:**
  - после перезапуска бот не публикует пропущенные посты пачкой;
  - один слот никогда не отправляется дважды — даже если бот упал посреди отправки;
  - ошибка в одном чате не мешает остальным: уведомление приходит вам, а после 5 ошибок подряд
    на паузу встаёт только этот чат рассылки;
  - если бота удалили из чата, рассылки просто пропускают этот чат и сами продолжат публиковать в него,
    когда бота вернут.
- **Доступ только у админов.** Можно указать несколько админов с одинаковыми правами, уведомления
  получают все. Сообщения и нажатия от других людей игнорируются. Если бота добавил в чат кто-то
  не из админов, бот спросит, принять этот чат или выйти из него.

## Быстрый старт

### 1. Создайте бота и узнайте ID админов

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте токен
   (вида `123456789:AA...`). Нужен **отдельный** бот: токен уже работающего бота использовать нельзя,
   иначе два бота будут мешать друг другу.
2. Узнайте числовые Telegram ID админов, например у [@userinfobot](https://t.me/userinfobot).

> Для премиум-эмодзи бота лучше создавать с аккаунта, у которого есть Telegram Premium
> (подробности — в разделе «Премиум-эмодзи» ниже).

### 2. Установите на сервер (Ubuntu / Debian) — рекомендуется

Подключитесь к серверу по SSH и выполните:

```bash
sudo git clone https://github.com/Crystalysdes/autopost.git /opt/autopost
sudo bash /opt/autopost/install.sh
```

Установщик спросит токен бота и ID админов (по одному, Enter — хватит), проверит токен в Telegram
и запустит бота. Если на сервере уже работают другие боты, они не затрагиваются:

- бот живёт только в своей папке `/opt/autopost` со своим окружением Python (`.venv`);
- работает как отдельная служба `autopost-bot` от системного пользователя `autopost`;
- ограничен по памяти (400 МБ) и приоритету, порты не открывает;
- установщик откажется брать токен, если его уже использует другой запущенный бот.

После установки каждый админ открывает бота в Telegram и отправляет `/start`.

**Если сервер не видит GitHub** (`git clone` зависает или пишет «Connection reset by peer»):
скачайте архив на компьютере (на GitHub: Code → Download ZIP), передайте его на сервер
(`scp autopost.zip root@IP_СЕРВЕРА:/root/`) и распакуйте в `/opt/autopost`:

```bash
python3 -c "import zipfile; zipfile.ZipFile('/root/autopost.zip').extractall('/tmp/autopost-new')"
sudo mkdir -p /opt/autopost && sudo cp -r /tmp/autopost-new/*/. /opt/autopost/
sudo bash /opt/autopost/install.sh
```

| Что сделать                      | Команда                                          |
|----------------------------------|--------------------------------------------------|
| посмотреть логи                  | `journalctl -u autopost-bot -f`                  |
| состояние                        | `systemctl status autopost-bot`                  |
| перезапустить                    | `sudo systemctl restart autopost-bot`            |
| поменять токен или админов       | `sudo bash /opt/autopost/install.sh --reconfigure` |
| обновить бота из GitHub          | `sudo bash /opt/autopost/install.sh --update`    |
| обновить из ZIP-архива           | `sudo bash /opt/autopost/install.sh --update-zip /root/autopost.zip` |
| удалить службу (данные остаются) | `sudo bash /opt/autopost/install.sh --uninstall` |

### Другие способы запуска

Настройки лежат в файле `.env` (образец — `.env.example`):

| Параметр    | Что это                                                        | По умолчанию       |
|-------------|----------------------------------------------------------------|--------------------|
| `BOT_TOKEN` | токен от @BotFather                                            | — (обязательно)    |
| `ADMIN_IDS` | Telegram ID админов через запятую                              | — (обязательно)    |
| `TIMEZONE`  | часовой пояс расписаний (потом можно сменить в боте)           | `Europe/Moscow`    |
| `DB_PATH`   | файл базы данных                                               | `data/autopost.db` |
| `LOG_LEVEL` | подробность логов                                              | `INFO`             |

**Docker:** `cp .env.example .env`, впишите токен и ID, затем

```bash
docker compose up -d --build
docker compose logs -f        # логи; выход — Ctrl+C
```

**Вручную** (нужен Python 3.11 или новее):

```bash
cp .env.example .env             # впишите токен и ID
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

## Как добавить чат

Любым из способов:

- **Кнопки «➕ Добавить группу» и «➕ Добавить канал» внизу экрана.** Telegram покажет ваши чаты
  и сам сделает бота администратором с нужными правами.
- **Вручную:** настройки группы или канала → Администраторы → добавить бота.
- Ссылками «➕ Группа» и «➕ Канал» в разделе «💬 Мои чаты».

Чат сразу появится в «💬 Мои чаты», а бот пришлёт уведомление.

Какие права нужны боту:

| Где    | Публикация                          | Закрепление                    | Удаление прошлого поста           |
|--------|-------------------------------------|--------------------------------|-----------------------------------|
| Группа | достаточно быть администратором     | «Закрепление сообщений»        | права не нужны (свои сообщения)   |
| Канал  | «Публикация сообщений»              | «Редактирование сообщений»     | «Публикация сообщений»            |

Для защиты групп (антиспам, обязательная подписка) боту нужно право **«Удаление сообщений»** — кнопка
«➕ Добавить группу» запрашивает его сама, а в уже добавленных чатах экран чата подскажет, если его нет.
Для обязательной подписки бот должен быть админом канала с правом **«Добавление подписчиков»**
(в некоторых версиях Telegram — «Пригласительные ссылки»): с ним бот создаёт каждому личные ссылки на канал.

Кнопка «🔄 Обновить права» на экране чата перечитывает права бота.

## Рассылки

**📬 Рассылки → «➕ Новая рассылка»** (или «➕ Новая рассылка» на экране чата — тогда этот чат уже отмечен),
затем:

1. **💬 Чаты.** Отметьте галочками чаты, в которые публиковать («☑️ Все» — все сразу). Изменения
   сохраняются сразу. Здесь же у форумов выбирается тема — у каждого чата своя.
2. **📝 Посты → ➕ Добавить посты.** Присылайте сообщения по одному — каждое станет постом.
   Можно переслать пост из своего канала: его кнопки подтянутся автоматически. В конце нажмите «✅ Готово».
3. **⏰ Расписание.** Задайте время или «N раз в день», дни недели, разброс и период.
4. **⚙️ Опции** — по желанию.
5. **👁 Предпросмотр** — бот пришлёт посты вам так, как они выйдут в чате.
6. **▶️ Запустить.**

Посты, расписание и опции общие для всех отмеченных чатов: в каждый слот расписания один и тот же пост
выходит во все чаты. Если в каком-то чате публикация не удалась, остальные чаты это не затрагивает,
а после 5 ошибок подряд на паузу встаёт только этот чат — снять её можно кнопкой «▶️ Возобновить»
в «💬 Чаты» (или на экране самого чата).

Если в рассылке несколько постов, за каждый слот расписания выходит один пост — по очереди или случайно.
Если пост в рассылке один, он выходит каждый раз. В карточке поста можно показать его, поменять кнопки,
заменить содержимое, передвинуть или удалить.

## Мои посты

**🗂 Мои посты** — все посты из всех рассылок и черновиков, новые сверху; у каждого видно, в какой он
рассылке. Откройте пост, чтобы:

- посмотреть его («👁 Показать»), изменить кнопки или содержимое, передвинуть или удалить;
- **✨ Новая рассылка с этим постом** — рассылка с копией поста, сразу открывается выбор чатов;
- **📋 Копировать в другую рассылку** — копия поста встаёт в конец выбранной рассылки или черновика.

**➕ Новый пост** — пришлите сообщение, и для него сразу появится рассылка: останется отметить чаты
и задать время.

### Кнопки под постом

Карточка поста → «🔘 Кнопки». Одна строка — один ряд, `|` разделяет кнопки в ряду:

```
Наш сайт - https://example.com
Канал - t.me/my_channel | Чат - @my_chat
Купить - https://shop.example.com - green
Промокод - copy:SALE2026 - blue
```

- Цвет кнопки: `green`, `red`, `blue` (или «зелёная», «красная», «синяя»).
- `copy:ТЕКСТ` — кнопка, которая копирует текст (например, промокод).
- Премиум-эмодзи в начале текста кнопки становится её иконкой.
- К альбомам Telegram не позволяет прикреплять кнопки.

### Режим пересылки

Если пост переслан (например, из вашего канала), в его карточке можно включить «↪️ Публиковать пересылкой».
Тогда пост уходит с плашкой «Переслано из…» и выглядит точно как оригинал, включая премиум-эмодзи.
Бот пересылает его из вашей переписки с ботом, поэтому не удаляйте исходное сообщение из этого чата.

## Черновики

- **💾 В черновики** на экране рассылки сохраняет её посты, расписание и опции.
- **📤 Применить к чатам** — отметьте чаты галочками и нажмите «🚀 Применить и запустить»
  (или «💾 Применить без запуска»). Из черновика получается одна рассылка на все отмеченные чаты;
  повторное применение добавляет новые чаты в неё же, а не создаёт дубли.
- В чате можно выбрать **«📝 Из черновика»** — чат добавится в рассылку из этого черновика.
- **🔄 Обновить рассылки** — после правки черновика изменения переносятся в рассылки, созданные из него
  (и в ту, из которой он был сохранён). Чаты, темы форумов, статус и счётчики при этом не меняются.

## Защита чатов: антиспам и обязательная подписка

Работает во всех группах, где бот — администратор с правом **«Удаление сообщений»**. Админы чата и бота
не проверяются. Бот ничего не пишет в чат о спаме — сообщения просто исчезают.

### Антиспам

Включён во всех группах сразу. Удаляются:

| Правило                | Что удаляется                                                                  |
|------------------------|--------------------------------------------------------------------------------|
| 🔗 Ссылки              | любые ссылки: сайты, `t.me/…`, скрытые ссылки в тексте, кнопки со ссылками — даже написанные с пробелами (`t . me/…`) |
| 🤖 Боты и каналы       | упоминания ботов и каналов (`@что-то_bot`, `@канал`), сообщения через инлайн-ботов, команды чужим ботам; «@вася» остаётся |
| ↪️ Пересылки           | пересланные сообщения, истории, ответы на сообщения из других чатов, розыгрыши |
| 📢 От имени каналов    | сообщения, написанные от имени чужого канала                                    |
| 🚫 Стоп-слова          | «заработок», «в лс», «без вложений», «казино», «18+» и т. п. — список можно менять; латинские буквы-двойники и невидимые символы бот распознаёт |
| 📇 Контакты и гео      | контакты, геопозиции, номера телефонов                                         |
| 👤 Реклама в имени     | сообщения людей, у которых в имени ссылка, `@ник` или стоп-слово                |
| 🚪 Вход и выход        | служебные «… вступил(а) в группу» и «… покинул(а) группу»                       |

- Спамный альбом удаляется целиком; если ссылку добавили правкой, сообщение тоже удаляется.
- Посты привязанного канала в группе обсуждения и анонимные админы не трогаются.
- **Для чата:** экран чата → «🛡 Защита» — выключить антиспам или отдельные правила, посмотреть
  «🗒 Последние удалённые» (журнал хранится две недели).
- **Для всех:** «⚙️ Настройки → 🛡 Антиспам»:
  - стоп-слова;
  - разрешённые ссылки (свой сайт или канал);
  - «Включить / Выключить во всех группах».

### Обязательная подписка

1. Добавьте бота администратором в канал, на который нужно подписываться.
2. «⚙️ Настройки → 🔒 Обязательная подписка → 📢 Общие каналы» — отметьте канал(ы) галочками.
   Подписка сразу нужна во всех группах.
3. Отдельной группе на экране «🛡 Защита» можно выбрать «Свои каналы» (другие галочки) или «Без подписки».

Если неподписанный пишет, его сообщение сразу удаляется, а бот на 5 минут показывает подсказку:

- кнопки «📢 <канал>» — **личные ссылки-приглашения**. Для каждого человека и каждой подсказки бот создаёт
  новые: вступить по такой ссылке может только один человек, через час она истекает. В списке ссылок канала
  они подписаны «Имя · id» — видно, кто по какой вступил;
- кнопка «✅ Проверить подписку». Подписался и нажал — подсказка исчезает, дальше можно писать.
  Если человек подписался и просто написал, сообщение остаётся, а подсказка тоже исчезает.

Пока подсказка висит, новые сообщения этого человека удаляются молча. Кто отпишется, снова не сможет писать.

Для личных ссылок боту нужно право «Добавление подписчиков» («Пригласительные ссылки») в канале. Без него
в подсказке обычная ссылка: `t.me/ник` у публичного канала, а у закрытого — общая ссылка, если бот успел
её создать, иначе кнопки на канал нет. Об этом бот раз в сутки напоминает админам. Если проверить подписку
не получается (например, бота убрали из канала), бот не блокирует чат, а раз в сутки пишет об этом админам.

## Премиум-эмодзи

Это ограничение Telegram, а не бота:

- **В группах** бот показывает премиум-эмодзи, если у **владельца бота** есть Telegram Premium.
  Владелец бота — аккаунт, который создал его в @BotFather (он может не входить в число админов).
- **В каналах** бот показывает премиум-эмодзи, только если ему куплен дополнительный юзернейм на
  [Fragment](https://fragment.com). Иначе они выглядят как обычные эмодзи. Обход — режим пересылки
  (см. выше).

«👁 Предпросмотр» сам проверяет, отобразились ли премиум-эмодзи, и подсказывает, если нет.

## Ограничения Telegram, о которых полезно знать

- Удалить прошлый пост можно, только пока ему меньше 48 часов. Если публикации реже, бот предупредит.
- Плашку «бот закрепил сообщение» бот удалить не может: Telegram не присылает ботам их собственные
  служебные сообщения.
- Подпись к медиа у ботов — до 1024 символов (у Premium-пользователей бывает длиннее, бот это проверит).
- Список тем форума через Bot API получить нельзя, поэтому тему задают ссылкой («💬 Чаты» рассылки →
  «🧵 Тема в …»): тема → ⋯ → «Копировать ссылку».

## Резервная копия и перенос

- **⚙️ Настройки → 💾 Резервная копия** — бот пришлёт файл базы со всеми чатами, рассылками и черновиками.
- Чтобы восстановить или перенести бота на другой сервер: остановите бота, положите файл на место базы
  (`/opt/autopost/data/autopost.db`, в Docker — том) и запустите бота снова.
- В Docker можно скопировать базу в текущую папку:
  `docker compose cp bot:/app/data/autopost.db ./autopost.db`.

Не запускайте два экземпляра бота с одной базой — второй сам откажется стартовать.

## Обновление

```bash
sudo bash /opt/autopost/install.sh --update                          # из GitHub
sudo bash /opt/autopost/install.sh --update-zip /root/autopost.zip   # из ZIP-архива
docker compose up -d --build                                         # Docker (после git pull)
```

**Из архива** — если сервер не видит GitHub: скачайте архив на компьютере (на GitHub: Code → Download ZIP),
передайте его на сервер (`scp autopost.zip root@IP_СЕРВЕРА:/root/`) и выполните команду `--update-zip`.
Настройки (`.env`), база (`data/`) и окружение Python остаются как были.

Если на сервере версия без `--update-zip` (обновляетесь из архива впервые), сначала положите новые файлы
вручную, потом запустите обычное обновление:

```bash
python3 -c "import zipfile; zipfile.ZipFile('/root/autopost.zip').extractall('/tmp/autopost-new')"
sudo cp -r /tmp/autopost-new/*/. /opt/autopost/
sudo bash /opt/autopost/install.sh --update
```

Если новая версия меняет формат базы, бот при первом запуске сам сохраняет копию старой базы рядом с ней
(например, `data/autopost-before-v2.db`) и переносит данные: рассылки, посты, чаты и счётчики сохраняются.

## Проверка после установки

1. `/start` — открылось меню, внизу кнопки «➕ Добавить группу/канал».
2. Добавьте бота в тестовую группу — пришло уведомление, чат появился в «Мои чаты».
3. «📬 Рассылки» → «➕ Новая рассылка», отметьте группу, добавьте пост с альбомом и пост с премиум-эмодзи
   и кнопками, нажмите «👁 Предпросмотр».
4. «🚀 Отправить сейчас» — пост появился в группе.
5. Задайте время на ближайшую минуту и нажмите «▶️ Запустить» — пост вышел по расписанию.
6. В «💬 Чаты» отметьте второй чат — следующий пост вышел в оба чата.
7. «🗂 Мои посты» — видны все посты; «✨ Новая рассылка с этим постом» создаёт рассылку с его копией.
8. Удалите бота из одной группы — пришло уведомление, а во второй чат посты продолжают выходить.
9. Со второго аккаунта (не админа) напишите в группу ссылку — сообщение исчезло.
10. Отметьте канал в «🔒 Обязательная подписка» и напишите в группу со второго аккаунта без подписки —
    сообщение удалено, появилась подсказка с личной ссылкой на канал. Подпишитесь по ней и нажмите
    «✅ Проверить подписку» — подсказка исчезла, писать снова можно.

## Частые вопросы

**Бот не отвечает на /start.** Проверьте ID админов (`sudo bash /opt/autopost/install.sh --reconfigure`).
В логах бот пишет `Игнорирую апдейт от постороннего пользователя <id>` — это настоящий ID того, кто писал.

**Чат не появился в списке.** Бот должен быть администратором (в группе можно и участником).
Нажмите «➕ Добавить группу/канал» внизу и выберите этот чат — бот зарегистрирует его.

**Посты не выходят.** Откройте рассылку: там статус, ближайшие запуски и ошибки по каждому чату. Проверьте:

- отмечены ли чаты в «💬 Чаты» и нет ли у какого-то из них паузы после ошибок;
- не стоит ли общая пауза (⚙️ Настройки);
- есть ли у бота права в чате;
- правильный ли часовой пояс.

**Время публикаций смещено.** Смените часовой пояс в «⚙️ Настройки → 🌍 Часовой пояс».
Расписания пересчитаются сразу.

## Для разработчиков

Python 3.11+, [aiogram 3.31](https://docs.aiogram.dev/) (Bot API 10.3), SQLAlchemy 2 + aiosqlite.

```
bot/
  __main__.py      запуск, блокировка второго экземпляра
  config.py        настройки из .env
  app.py           контейнер зависимостей и настройки, меняемые из бота
  setup.py         сборка диспетчера (middleware и порядок роутеров)
  db/              модели, подключение к SQLite, перенос данных между версиями и репозиторий
  handlers/        обработчики: команды, чаты, рассылки, чаты рассылки, посты, «Мои посты», расписание,
                   опции, черновики, настройки, защита групп (moderation, protection)
  middlewares/     доступ только админам, сборка альбомов
  services/        планировщик, отправка постов, приём контента, кнопки, расчёт расписания,
                   распознавание спама (spam) и защита групп (moderation)
  ui/              экраны, клавиатуры, тексты, callback-данные
tests/             юнит- и интеграционные тесты (фейковый Telegram записывает запросы бота)
install.sh         установщик для Ubuntu/Debian: venv, пользователь, служба systemd
```
